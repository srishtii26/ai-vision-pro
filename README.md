# 🤖 AI Vision Pro – Intelligent Image Classification Platform

A modern AI-powered Image Classification Platform built using Flask, TensorFlow, MobileNetV2, Computer Vision, HTML, CSS, and JavaScript to analyze, classify, and generate intelligent insights from uploaded images.

The platform combines image classification, confidence analysis, image metadata extraction, drag-and-drop uploads, dashboard analytics, and interactive visualizations into a unified AI workspace.

---

# 🚀 Overview

The AI Vision Pro Platform is a recruiter-level AI/ML project designed to simulate real-world computer vision systems used in:

* Smart Surveillance
* Retail Automation
* Healthcare Imaging
* Agriculture Monitoring
* Manufacturing Inspection
* Intelligent Image Analytics

The platform helps users:

* Upload and analyze images
* Identify objects using AI
* View confidence scores
* Analyze image metadata
* Explore top AI predictions
* Interact with a modern AI dashboard

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/srishtii26/ai-vision-pro.git
```

## 2️⃣ Navigate Into Project

```bash
cd ai-vision-pro
```

## 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

## 4️⃣ Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

## 5️⃣ Install Dependencies

```bash
pip install flask tensorflow numpy pillow
```

## 6️⃣ Run Application

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

# 📊 Application Workflow

### Step 1

Upload or drag-and-drop an image.

### Step 2

Preview the image before submission.

### Step 3

The AI model processes the image using MobileNetV2.

### Step 4

Receive:

* Top prediction
* Confidence score
* Top 3 predictions
* Image metadata

### Step 5

Analyze results through the interactive dashboard.
